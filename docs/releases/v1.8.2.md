# MagicNet v1.8.2（MagicNet-Mod）

本版是 `RyanRaw/MagicNet-Mod` 基于上游 MagicNet v1.8.0 的第一个正式版本：合入上游 v1.8.0 的全部功能，保留本 Mod 的自建 Tailscale 控制服务器支持，并把整套更新通道指向本仓库。

## 来自上游 v1.8.0

- 节点与代理组页新增应用、域名和自定义组/出口编辑，草稿先预览，再保存并应用。
- 自定义项通过有归属的增量层生成，保留订阅和系统管理项；订阅更新重新生成时保留自定义项，撤销时保留订阅新增项。发生名称碰撞、组循环或外部冲突时拒绝覆盖。
- 应用选择可读取 Android 主用户的应用名称，支持名称和包名搜索。清单与凭据不进入通用操作输出。
- WebUI 改为矿白、石墨与玉绿配色，保留 14 个页面、原有操作流程、中英俄切换与浅深色主题。
- 包含上游合并的四个修复：透明模式 fork（PR #420）、代理组可访问性（#421）、installer 迁移清单（#422）、生命周期竞争（#423）。

## 本 Mod 的改动

- **自建 Tailscale 控制服务器（Headscale）**：Tailscale 卡片可填写 Headscale 的 `server_url`，并作为 endpoint 的 `control_url` 保存；登录链接只在已保存的 origin 上打开；切换服务器需要新服务器签发的 key 或先登出。详见 `docs/tailscale.md`。
- **更新通道指向本仓库**：应用内更新检查（最新发布接口、资源接口、下载地址）、组件清单的 `repository` 校验、默认打包仓库、KernelSU 元数据主页与反馈入口、WebUI 的仓库常量，全部改为 `RyanRaw/MagicNet-Mod`。此前指向上游的话，本仓库自己打出的组件清单会被拒绝加载。
- **版本号**：`v1.8.2` / `versionCode 10610`，高于上游 v1.8.1 的 10609，避免被上游包降级。
- **CI 适配**：runner 镜像升级后的四处修正——探针在 JDK 25 下把提前中断的响应体归类为 `short_body`；快照测试的模拟进程改用解释器（新版 runner 的 coreutils 拒绝以其它工具名运行）；发布门禁补齐 `mksh` 等宿主依赖；WebUI 编辑器长文本输入在共享 runner 上的超时预算。

## 安装与更新

Android arm64 root 模块。`MagicNet-full.zip` 是完整离线包，适合全新安装；`magicnet_installer.zip` 通过已发布的组件清单获取组件。安装前保留自己的配置，更新后按管理器提示重启。下载后可用同一发布页的 `SHA256SUMS` 核对完整性；这不是私钥签名。

本版的 `update.json` 指向本仓库的 `releases/latest`，已安装本模块的用户此后检查更新会从本仓库获取。

默认透明代理仍为 `tun`（`magicnet0`），仅支持显式切换 `tun|ebpf`。eBPF 仍受设备内核能力限制。

## 验证范围

发布前执行 Rust、Go 组件、WebUI 单元与六个视口的浏览器测试、Shell 与整体质量门禁，全部通过后才创建 Release。Android 侧是通过 x86_64 模拟设备（AVD）的 KernelSU 验收与契约测试，不等于真机验证。多厂商 Play/GMS、热点双栈、Tailnet 连通性及长期性能场景仍需各自的真实设备证据。
